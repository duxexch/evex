## 🚀 Deployment Workflow

### First-Time Deployment
```bash
# 1. On your local machine
scp setup_vps.sh root@your-vps-ip:/root/

# 2. On VPS as root
ssh root@your-vps-ip
bash /root/setup_vps.sh
cat /root/langsense_credentials.txt  # Save these!

# 3. Clone repository
sudo -u langsense -i
cd /opt/langsense
git clone https://github.com/promnes/botv.git .

# 4. Configure environment
cp .env.production.template .env
nano .env  # Edit with real values

# 5. Setup services (copy from PRODUCTION_DEPLOYMENT_CHECKLIST.md)
# Create /etc/systemd/system/langsense-bot.service
# Create /etc/systemd/system/langsense-api.service

# 6. Install dependencies
python3.11 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# 7. Initialize database
alembic upgrade head

# 8. Configure Nginx and SSL
# (Follow PRODUCTION_DEPLOYMENT_CHECKLIST.md section 3 & 8)

# 9. Start services
sudo systemctl daemon-reload
sudo systemctl enable langsense-api langsense-bot
sudo systemctl start langsense-api langsense-bot

# 10. Verify
curl http://localhost:8000/health
```

### Subsequent Updates
```bash
# Simple one-command deployment
cd /opt/langsense
sudo -u langsense bash deploy.sh
```

## 🔄 Update Procedures

### Application Updates
```bash
# Standard update process
cd /opt/langsense
sudo -u langsense bash deploy.sh
# Script handles: backup, pull, deps, migrations, restart, health checks
```

### Database Schema Changes
```bash
# Create migration
alembic revision --autogenerate -m "description"

# Apply migration
alembic upgrade head
```

### Rollback Procedure
```bash
# Stop services
sudo systemctl stop langsense-api langsense-bot

# Restore database
sudo -u postgres psql langsense < /opt/langsense/backups/backup_YYYYMMDD.sql

# Revert code
git reset --hard <previous-commit>

# Restart
sudo systemctl start langsense-api langsense-bot
```

## 🆘 Troubleshooting Guide

### API Won't Start
```bash
# Check logs
journalctl -u langsense-api -n 100

# Test manually
cd /opt/langsense && source venv/bin/activate
python -m uvicorn api.main:app --host 0.0.0.0 --port 8000

# Common issues:
# - Missing .env file
# - Wrong DATABASE_URL format
# - Port 8000 already in use
```

### Bot Not Responding
```bash
# Check logs
journalctl -u langsense-bot -n 100

# Test manually
cd /opt/langsense && source venv/bin/activate
python bot.py

# Common issues:
# - Invalid BOT_TOKEN
# - Database connection failed
# - Missing admin user IDs
```

### Database Connection Errors
```bash
# Check PostgreSQL
sudo systemctl status postgresql
sudo -u postgres psql -l

# Test connection
psql -U langsense -d langsense -h localhost

# Check .env
grep DATABASE_URL /opt/langsense/.env
```
